اضغط تشغيل لمشاهدة أجواء المدينة والفعاليات

📖 دليل لوحة التحكم الشاملة

1. إدارة اللاعبين: ابحث عن اللاعب → اضغط حظر مع كتابة السبب أو فك حظر أو منح مكافأة مالية فورية أو ترقية الرتبة.
2. المتجر والأسعار: عدّل السعر يدوياً داخل الجدول أو استخدم أزرار الزيادة/التخفيض الجماعي (+10% / -20%) لتطبيق خصم شامل فوراً.
3. تعديل نصوص الموقع: تبويب "تعديل نصوص الموقع" يسمح لك بتغيير عنوان الهيرو والوصف ونص البانر العلوي ورابط الديسكورد و IP السيرفر بدون كود.
4. المظهر: غيّر لون الثيم، خلفية الموقع، وصورة الهيرو بالأزرار الجاهزة أو عبر إدخال رابط صورة مخصص.
5. الطلبات والفواتير: راجع طلبات الشراء → وافق لإضافة الرصيد للاعب أو ارفض مع استرداد.
6. البث المباشر: اكتب رسالة وحدد الفئة المستهدفة لإرسال إشعار فوري يظهر كـ Toast لكل الزوار.
